# Проверка VirtusPlanner 7 октября 2026

## Обновление дизайна

Нижняя навигация выполнена плавающей овальной капсулой по предоставленному примеру. Вокруг неё нет сплошной подложки: экран продолжается под панелью, а полупрозрачный градиент мягко затемняет содержимое снизу. Пять разделов подписаны, активная вкладка выделена бирюзовым. Нижний отступ в прокручиваемых списках позволяет поднять последнее дело выше панели и нажать на него. При открытии клавиатуры панель скрывается.

Изменено расположение блоков: «Сегодня» показывает фокус, прогресс и хронологический список дел; календарь по умолчанию показывает неделю с раскрытием месяца, переходом между неделями и возвратом к сегодняшней дате. Создание задачи перенесено в заголовок, счётчики типов сохранены. Профиль стал компактным, действия помощника расположены сеткой, аналитика объединяет процент выполнения и показатели в обзорной карточке. Форма задачи прокручивается при открытой клавиатуре.

Проверка TypeScript и 44 теста проходят. Собран Android APK для arm64 и x86_64. iOS на устройстве не проверялся.

Исправлены геолокация в чате, поиск мест поблизости, повторные геоуведомления, счётчики категорий календаря и ошибки в нескольких связанных сценариях. Проверено существующее приложение в корне репозитория. Вложенная папка `VirtusPlanner` содержит отдельную старую копию; её исключили из проверки TypeScript и тестов.

## Отличия от описания проекта

Описание в предоставленном документе шире существующей реализации. Следующие пункты ещё не реализованы и не могут считаться проверенными работающими функциями:

- Синхронизация с Яндекс Календарём и календарём устройства.
- Отдельный трекер привычек и повторяющиеся задачи.
- TensorFlow Lite, ансамбли моделей, генетическая оптимизация и обучение по истории пользователя. Сейчас используются YandexGPT, локальные правила и обычная статистика.
- Серверная архитектура с PostgreSQL, Redis, Docker и Kubernetes.
- JWT, многофакторная аутентификация, защищённое хранение ключей и заявленное шифрование локальных данных. Профиль локальный, данные хранятся в AsyncStorage. Ключи API подставляются в сборку из локального файла `.virtus-secrets.json`, исключённого из Git; это не заменяет серверное хранение секретов.

Создание этих подсистем требует отдельной реализации. Исправления текущей проверки не означают, что весь описанный в документе проект уже реализован.

## Ограничения среды

На телефоне при запуске существующего отладочного APK Android показал предупреждение о библиотеках без выравнивания для страниц памяти 16 КБ. Проект использует React Native 0.73.8; полноценную совместимость с устройствами с такими страницами потребуется проверять после обновления нативных зависимостей.

Первый внешний сервер поиска на мобильном соединении не отвечал. Основным выбран доступный сервер VK Maps той же базы OpenStreetMap, резервным оставлен overpass-api.de. Публичные серверы и полнота адресов могут влиять на результаты. Перечень серверов: [OpenStreetMap](https://wiki.openstreetmap.org/wiki/Overpass_API#Public_Overpass_API_instances).

На компьютере сборке мешали кириллица в пути и кодировка Gradle. Добавлены UTF-8 и разрешение такого пути. Недостающие Maven-артефакты скачаны из официальных репозиториев во временный локальный репозиторий для проверки сборки; версии зависимостей сохранены.

Для продолжения доступа к координатам при сворачивании используется сервис Android типа location, запускаемый при видимом приложении: [документация Android](https://developer.android.com/training/permissions/requesting). После принудительной остановки приложения в настройках Android необходимо вновь открыть приложение. Доступность публичных серверов карты влияет на своевременность проверки.
